# database

USW SYNC의 데이터베이스 설계 및 관리 파일을 저장할 공간입니다.

## 관리 예정 대상

- 사용자 정보
- 팀 및 팀원 정보, 초대와 참여 관계
- 개인 시간표와 활동 가능 시간
- 회의 후보 시간, 투표 및 확정 일정
- 팀원별 역할, 할 일, 마감일 및 진행 상황

PostgreSQL을 사용하고 Supabase를 활용할 계획이지만 최종 확정 사항은 아닙니다. 추후 SQL 스키마, 마이그레이션과 테스트 데이터를 관리하며, 데이터베이스 설계 문서는 `docs/`에 정리할 예정입니다.

현재 테이블·SQL·마이그레이션·테스트 데이터는 생성하지 않았습니다. 담당 업무와 데이터 모델을 합의한 후 하위 디렉터리와 파일을 추가합니다. 팀원 모집·공개 모집글·지원자 매칭 데이터는 설계 범위에서 제외합니다. 실제 개인정보나 비밀값을 테스트 데이터 또는 Git에 저장하지 않습니다.
